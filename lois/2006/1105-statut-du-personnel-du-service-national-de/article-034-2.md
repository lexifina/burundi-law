# Article 34 2

Par ordre croissant, la catégorie des Agents comprend les grades suivants : Agent de Police de 3ème Classe :AP3

- Agent de Police de 2ème Classe :AP2

- Agent de Police de 1ère Classe : API

- Agent de Police Principal de 3ème Classe :APP3

- Agent de Police Principal de 2ème Classe : APP2

- Agent de Police Principal de 1ère Classe : APPl Agent de Police Chef de 3ème Classe :APC3

- Agent de Police Chef de 2ème Classe :APC2

- Agent de Police Chef de 1ère Classe :APCI
