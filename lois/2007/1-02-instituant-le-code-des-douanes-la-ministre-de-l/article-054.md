# Article 54

16. Sans préjudice des dispositions de l'article 186 du Code des Douanes, sont exclues de l'en-trepôt public les marchandises suivantes : 17. les acides chlorhydriques, fluorhydriques, nitriques, sulfuriques et tous les acides pou-vant constituer un danger pour le personnel et les marchandises entreposées ; 18. les allumettes chimiques et soufrées y com-pris les briquets ; 19. les artifices de guerre ou de divertissement ; 20. les chaux et les ciments ; 21. le charbon de terre, le coke, les briquettes et les boulets ; 22. les engrais ; 23. le goudron, le coaltar et les huiles essen-tielles ; 24. les produits pétroliers, le naphte et les huiles minérales ; 25. les poissons séchés, les poissons frais et les viandes fraîches ; 26. le sel en sacs; 27. les marchandises en vrac ; les insecticides, les herbicides et les fongi-cides ; ENTREPOT PRIVE
