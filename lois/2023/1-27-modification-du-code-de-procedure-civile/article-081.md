# Article 81

Ingingo ya 81 Les fins de non-recevoir, peuvent être proposées en tout état de cause, sauf la possibilité pour le juge de condamner à des dommages-intérêts ceux qui se seraient abstenus de les soulever plutôt dans une intention dilatoire. Imburano zisaba ko urubanza rutokwakirwa zishobora gushikirizwa uko ziba ziri kwose ariko umucamanza akaba ashobora guha igihano c’ugu-tanga indishi aboba banse kubishikiriza hakiri kare bafise intumbero yo kudindiza urubanza.

Le juge se prononce dans un délai ne dépassant pas huit jours. Umucamanza afata ingingo mu kiringo kitarenza imisi umunani.
