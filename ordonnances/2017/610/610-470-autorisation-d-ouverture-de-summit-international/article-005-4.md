# Article 5 4

Constituent notamment des produits forestiers non ligneux: - le bois de chauffage au sens du Code Forestier; - tous les rotins; - les marantacées (feuilles et tiges); - les bambous; - les champignons; - le palmier raphia (tiges et feuilles); - les plantes médicinales; - les feuilles comestibles; - les fruits et gommes sauvages; - les écorces; - les plantes fourragères; - les huiles; - le nyme; - le Typha sp.; - tous cypéraceaes; - les produits d’origine animale y compris le miel, les insectes/criquets, les escargots, les vers blancs/hannetons; - Etc.
