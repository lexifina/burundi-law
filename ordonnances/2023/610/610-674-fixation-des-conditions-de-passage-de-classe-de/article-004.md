# Article 4

Le jury de délibération est composé des personnes suivantes :

a) pour les classes montantes :

- le directeur d’établissement ;

- le directeur technique ;

- le préfet des études ;

- les membres du corps enseignant ;

- le préfet de discipline ;

- les encadreurs de discipline.

b) pour les classes terminales :

- le directeur d’établissement ;

- le directeur technique ;

- le préfet des études ;

- les enseignants des classes terminales;

- le préfet de discipline.
