# Article 17

Les Brigades Régionales comprennent : 1. Brigade Centre-Est ; 2. Brigade Ouest; 3. Brigade Sud ; 4. Brigade Nord. ► La Brigade Centre -Est comprend : - Un chef de Brigade ; - Quatre cadres techniques d’appui ; - Six techniciens conducteurs des travaux ; - Un mécanicien ; - Deux chauffeurs d’engins ; - Deux chauffeurs de véhicule léger ; - Deux sentinelles ; - Un planton. ► La Brigade Ouest comprend : - Un chef de Brigade ; - Cinq cadres techniques d’appui ; - Quinze techniciens conducteurs des travaux; - Deux chauffeurs véhicule léger ; - Un opérateur. ► La Brigade Sud comprend : - Un chef de brigade - Trois cadres techniques d’appui ; - Six techniciens des conducteurs des travaux; - Un mécanicien ; - Un opérateur - Deux chauffeurs véhicule léger. ► La Brigade Nord - Un chef de brigade ; - Trois cadres techniques d’appui ; - Quatre techniciens conducteurs des travaux ; - Deux chauffeurs véhicule léger ; - Un mécanicien.
