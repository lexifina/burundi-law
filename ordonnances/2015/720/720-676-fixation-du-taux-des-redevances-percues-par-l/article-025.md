# Article 25

Les redevances pour les inspections de nuit ou qui se prolongent dans la nuit sont majorées de 20%.

Les redevances pour les inspections effectuées les jours fériés et les jours de repos sont majorées de 25%.

Les redevances pour les inspections effectuées de nuit ou qui se prolongent dans la nuit les jours fériés et les jours de repos sont majorées de 30%.
