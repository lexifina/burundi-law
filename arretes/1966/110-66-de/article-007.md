# Article 7

La vitesse et la pression de remplissage des récipients à acétylène dissous seront telles que la pression dans le récipient ne dépasse à aucun moment 35 kilogrammes par centimètre carré. - pour l'ammoniac (N H,) : le bleu et le blanc; - pour l'anhydride carbonique ( CO,) : le gris ~ pour l'anhydride sulfureux (S 0,) : le rouge et le blanc i - pour l'argon (Ar) : le jaune et le blanc i - pour l'azote (N) : le noir i - pour le carbogène (0, + CO,) : le blanc et le gris; ~ pour le chlore (Cl ) : le vert ; - pour le cyclopropane (e" H,) : l'orange - pour l'éthylène (C, H,) : le violet; - pour l'hélium (He) : le brun; - pour l'hydrogène (H) : le rouge et le vert; - pour l'oxygène (0,) : le blanc i - pour le mélange d'oxygène et hélium (0, +He) le blanc et le brun i - pour le protoxyde d'azote (N,O) : le bleu. Lorsque deux teintes sont prescrites, la peinture doit être appliquée par quariers alternés comme indiqué dans 13. figure ci-dessous. VIII. TARE ET CAPACITE EN EAU.
