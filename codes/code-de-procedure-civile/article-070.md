# Article 70

L’intervention est l’acte par lequel un tiers qui, originairement, n’était pas partie dans une instance s’y présente ou est appelé à y prendre part. Elle est dite volontaire lorsqu’un tiers intervient spontanément dans la cause ; elle est dite forcée ou mise en cause lorsqu’une assignation est dirigée par le demandeur ou le défendeur contre un tiers.
