# Article 62

Le système ferroviaire est découpé en sous-systèmes suivants : 1 ° 1’ infrastructure ;

2° l’énergie de traction;

3° le contrôle-commande et la signalisation ;

4° le matériel roulant destiné au transport de marchandises ;

5° le matériel moteur et le matériel voyageur ;

6° l’exploitation ;

7° la sécurité dans les tunnels ;

8° le bruit;

9° les personnes à mobilité réduite ;

10° les applications télématiques pour les marchandises ;

11° les applications télématiques pour les voyageurs.
