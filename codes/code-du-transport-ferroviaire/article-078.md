# Article 78

L’Autorité de régulation ferroviaire peut délivrer des autorisations par type de véhicule. L’autorisation pour un véhicule porte également sur le type de véhicule correspondant.

Le véhicule conforme à un type de véhicule qui a déjà été autorisé sur le réseau d’un pays partenaire est autorisé sur le réseau burundais sur base d’une déclaration de conformité avec le type de véhicule fourni par le demandeur, sans autre vérification.
