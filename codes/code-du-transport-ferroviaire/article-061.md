# Article 61

Les exigences essentielles portent sur les aspects techniques et les aspects réglementaires.

Les aspects techniques concernent : 1 ° l’écartement des rails ;

2° les signalisations électriques et visuelles ;

3° les normes d’électrification harmonisées sur les différentes tensions et fréquences ;

4° la longueur des trains limitant les contraintes techniques ;

5° le gabarit.

Les aspects réglementaires concernent : 1 ° l’aptitude à la conduite des trains ;

2° le contrôle des produits transportés ;

3° les horaires.
