# Article 76

Le plan d'aménagement porte sur une entité géographique appelée unité forestière d'aménagement, définie par ordonnance du ministre ayant les forêts dans ses attributions. L'unité forestière d'aménagement est divisée en unités forestières de gestion dont le nombre d'assiettes annuelles de coupe est déterminé selon les normes officielles d'intervention prévues à l’article 14.
