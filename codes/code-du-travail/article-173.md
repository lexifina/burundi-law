# Article 173

Les travailleurs licenciés pour motif économique peuvent faire valoir, pendant une durée d’un an, leur droit à l’embauche prioritaire, sans compétition lorsqu’ils remplissent le profil requis pour le poste auquel l’employeur souhaite pourvoir, en cas de réouverture ou de création d’emplois de leurs spécialités dans l’entreprise.
