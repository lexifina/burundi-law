# Article 421

Si les immeubles dont l’expropriation est envisagée sont grevés de droits réels, le propriétaire est tenu d’aviser sans délai les titulaires de ces droits afin qu’ils puissent pourvoir à la défense de leurs intérêts. A défaut, le propriétaire est tenu envers eux des indemnités qu’ils auraient pu obtenir.
