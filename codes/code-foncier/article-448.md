# Article 448

Toutes les terres de marais sont délimitées par les soins du ou des Ministres ayant les terres dans leurs attributions.

Sur base d’une étude appropriée, la délimitation d’un marais peut inclure les bas fonds situés dans sa zone d’extension prévisible.

Les terres de marais domaniaux sont inscrites à l’inventaire des biens de l’Etat.
