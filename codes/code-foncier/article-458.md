# Article 458

Le certificat d’enregistrement défini dans la Loi n°1/008 du 1er septembre 1986 portant Code Foncier est dénommé Titre foncier au sens de la présente loi.

Le livre d’enregistrement défini dans la Loi n°1/008 du 1er septembre 1986 portant Code Foncier est appelé Livre foncier dans le présent Code.
