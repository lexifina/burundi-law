# Article 269

L’Officier du Ministre Public informe l’inculpé qu’il a le droit de se choisir un avocat. Il est fait mention de cette formalité dans le procès-verbal d’audition contresigné avec l’inculpé. Toutefois, l’assistance d’un défenseur est obligatoire quand l’infraction pour laquelle l’inculpé est poursuivi est punie d’au moins vingt ans de servitude pénale.
