# Article 280

Est qualifiée « escalade » toute entrée dans les maisons, bâtiments, cours, basses-cours, édifices quelconques, jardins, parcs, enclos, exécutée par-dessus les murs, portes, toitures ou toute autre es-pèce de clôture ; l'entrée par une ouverture autre que celle qui a été établie pour servir d'entrée. §8.
