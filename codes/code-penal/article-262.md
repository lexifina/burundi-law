# Article 262

Le vol est puni de cinq ans à sept ans de servi-tude pénale s'il est commis avec l'une des circons-tances suivantes :

1° Lorsqu'il est commis par une personne déposi-taire de l'autorité publique ou chargée d'une mission de service public ;

2° Si le coupable a agi en prenant le titre ou les insignes d'un fonctionnaire public ou en alléguant un faux ordre de l'autorité pu-blique ;

3° Si le vol a été commis dans un local d'habi-tation ou ses dépendances ou dans un lieu utilisé ou destiné à l'entrepôt de fonds, va-leurs, marchandises ou matériels ;

4° Si le vol a porté sur un véhicule motorisé ;

5° Si le vol a porté sur le bétail ;

6° Si le vol a été commis par une personne travaillant habituellement dans l'habita-tion où elle a volé.
