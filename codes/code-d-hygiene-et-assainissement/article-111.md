# Article 111

Les vendeurs de denrées alimentaires immédiatement consommables telles les bouillies, les pâtes diverses, les brochettes, les gâteaux, les produits laitiers, les glaces, les jus de fruits doivent les protéger de manière adéquate et hygiénique notamment dans des glacières. Ils doivent assurer la propreté des abords immédiats de leur commerce.
